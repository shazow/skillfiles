# skillfiles

SKILL.md files

| skill | what it does |
|---|---|
| [`protocol-design`](protocol-design) | Design, specify, and iterate on software protocols and their specs. Distilled from the design of the [Apron](https://github.com/shazow/apron) protocol. |

Each skill is a directory with a `SKILL.md`. To install one, copy its
directory into `~/.claude/skills/` (or a project's `.claude/skills/`).

Test prompts and results for a skill live in `evals/<skill>/`.
